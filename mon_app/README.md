# Mon App

App AXIS-OS générée par `axis-os init`.

## Développement

```bash
axis-os simulate    # teste dans le simulateur
axis-os publish      # publie sur le Play Store
```

## Structure

```
mon_app/
├── app.py           # logique de votre app
├── manifest.json    # métadonnées Play Store
├── test_app.py       # tests
└── README.md
```
